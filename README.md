# Abriendo el Foco — Landing

Landing page de portfolio para el proyecto "Abriendo el Foco" (Testeha Estudio × Asociación Achalay).

Sitio estático de una sola página (`index.html`), sin dependencias ni build step — se puede desplegar tal cual en Vercel, Netlify, GitHub Pages o cualquier hosting estático.

## Desarrollo local

Abre `index.html` directamente en el navegador, o sirve la carpeta con cualquier servidor estático:

```bash
npx serve .
```

## Despliegue en Vercel

1. Sube este repositorio a GitHub.
2. Entra en [vercel.com](https://vercel.com) → **Add New Project** → importa el repositorio.
3. Framework Preset: **Other** (sitio estático). No hace falta build command ni output directory.
4. Deploy.

Vercel generará automáticamente una URL temporal del tipo `abriendo-el-foco-xxxx.vercel.app`.
